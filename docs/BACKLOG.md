## 明确暂缓

### 密码保险箱（随身笔记加密升级）
- **状态**：暂缓，不做。除非将来的 Issue 明确提出「需要密码保险箱 / 主密码 / 跨设备解密」这类需求，才重新评估。
- **背景**：随身笔记目前把 Key、取件码这类内容打码显示（点眼睛看明文、点击复制），但磁盘上是明文 JSON。要做真正的保险箱有两条路：
  - **A（推荐打底）**：Windows DPAPI 加密，和当前登录账户绑定。零输入成本，但重装系统或换机器就解不开。
  - **B（A 之上）**：另加主密码，用 Argon2id 派生密钥。跨机器/重装能解，代价是每次打开要输一次密码。
- **如果哪天要做**：先做 A，把存储层留出算法标识与升级位，B 后续再叠加，避免一次性上主密码把「随手记」变成「先登录」。
- **风险备注**：主密码方案要处理忘记密码 = 数据永久打不开、以及解锁后内存中明文生命周期的问题；不是加个加密函数就完事。

## 小打磨（已有功能的手感）

- **面板卡片拖动排序**：现在是按置顶、更新时间排序，不能手动排。
- **双击标题就地改名**：面板里改标题要打开便签。
- **Esc 分层退出**：编辑态 / 灯箱 / 菜单 / 多选态 / 面板 的退出顺序统一成一层一层退，不要一次全关。
- **模拟真实粘贴验证**：照片的 `Ctrl+V` 走的是剪贴板读取路径，只验证了拖入；需要真机粘贴一次截图确认。
- **Markdown 关闭时的照片**：关掉「Markdown 排版」后照片不渲染（照片依赖 Markdown 渲染器）。要么让照片脱离 Markdown 开关，要么在设置里说明。
- **灯箱多图 ←/→**：代码有，未真机验证两张以上图片的切换。
- **空列表引导**：搜索/筛选无结果时已有「清除筛选」，可以再加一句「怎么记第一条」的引导。

## 需要外部条件

- **代码签名**：申请 SignPath Foundation 免费证书（需要本人信息、仓库公开、项目有一定可见度），过审后 CI 自动签名，SmartScreen 提示才会逐步消失。
- **发布 v0.2.4**：tag + push 触发 CI Release（等确认）。

## 想过但明确不做

- 多端同步 / 云账号：和「数据只在本机」的定位冲突，也违背轻量。
- 复杂 Markdown（表格、脚注、公式）：便签是纸，不是文档编辑器。
- 主题商店 / 自由缩放：窗口尺寸三档 + 六色已经够用，再多是维护负担。
- 单窗口多便签（标签页）：会破坏「一张纸在桌面上」的核心体验。
